# Physics

## Overview
In this simulation, we want to be able to see what is the effect of bootstrap current in the functioning of a toroidal, tokamak-like, reactor. For this purpose, we will start by first inducing a current into the plasma by using the central solenoid, which is a crucial part of tokamak reactors. The central solenoid will ramp up the plasma's current up to a certain value, and maintain that value during flat top operation.  
While this happens, we will also be calculating the current that arises as a bootstrap current. The effects of this current will be most noticeable during flat-top, when the central solenoid is no longer increasing the plasma's current. Then, we will calculate the bootstrap current and keep track of it during the whole duration of the experiment.  
At the end, we will analyze the plasma's current values during the experiment, comparing the fractions that are due to the central solenoid and due to the bootstrap current. With this, we want to find out how much of a plasma's current can be expected to come from this self generated bootstrap current, and up to what values can the total plasma current climb up to.

## Characterization
The simulation will be made for a plasma with a cross sectional radius ${ R_{ p } }$, with particle density ${ n }$, in a reactor with a central solenoid that can carry a maximum current of ${ I_{ \text{max} } }$, through a total length of time ${ T }$ . This will be the characteristic quantities that will be used to normalize all other related variables.  

## Central solenoid induction
The first thing we need to do is to create a current profile for the central solenoid (CS). This profile needs to be such that we can induce a current into the plasma, make it climb to a certain value (this is the ramp-up phase), and then maintain it at that value during flat-top. The current ${ I_{ cs } }$ that we induce into the plasma will be proportional to the change in the magnetic flux created by the CS:  

$$  
\begin{align*}
    I_{ cs } &\propto -\dfrac{ d \Phi  }{ d t } 
\end{align*}
$$  

### CS magnetic field
To find the flux $\Phi$, we need to calculate the magnetic field that is generated by the CS due to the current flowing through it. We can do this by using Biot-Savart's law: 

$$
\begin{align*}
    \vec{ B } ( \vec{ r }  ) &=  \dfrac{ \mu_{ 0 } I}{ 4 \pi } \displaystyle\int\limits_{ C }^{  } \dfrac{ \text{d} \vec{ l } \times \left( \vec{ r } - \vec{ r }'  \right)   }{ \left \lVert \vec{ r }  -\vec{ r } ' \right \rVert ^{ 3 }  }
\end{align*}
$$

Where ${ \vec{ r } }$ is a vector pointing to a point in space, ${ \vec{ r }' }$ is pointing to a point in the coil and ${ \vec{ l } }$ is the vector that describes the trajectory ${ C }$ that the current ${ I }$ (which was taken as independent of the point in space) follows through the coil. To apply this computationally, we normalize every vector by dividing it by ${ R_{ p } }$, as well as the current ${ I }$ by dividing by ${ I_{ \text{max} } }$, and so the actual value of the magnetic field ${ \vec{ B } }$ would be given like:

$$
\begin{align*}
    \vec{ B } &= \dfrac{ \mu_{ 0 } I_{ \text{max} } }{ 4 \pi R_{ p } } I \int  \dfrac{ \text{d} \vec{ l } \times \left( \vec{ r } - \vec{ r }'  \right)   }{ \left \lVert \vec{ r }  -\vec{ r } ' \right \rVert ^{ 3 }  }\\
    &= \dfrac{ \mu_{ 0 } I_{ \text{max} } }{ 4 \pi R_{ p } } I \vec{ F } 
\end{align*}
$$

Replacing values in the international system of units, this field would give in Teslas (T).  

### Field flux
The next step to calculate the current the CS induces in the plasma would be to calculate the flux of this field through the area covered by the plasma. We do this by defining the vector ${ \vec{ A } }$ that describes the this area covered by the plasma loop ${ P }$. The flux would then be:

$$
\begin{align*}
    \Phi &= \int\limits_{ P } \vec{ B } \cdot \text{d} \vec{ A } \\
    &= \dfrac{ \mu_{ 0 } I_{ \text{max} } R_{ p } A_{ cs } }{ 4 \pi } I \int \vec{ F } \cdot \hat{ n } \text{d}{ \hat{ A }  } 
\end{align*}
$$

Where the second line corresponds to the normalized expression. ${ A_{ cs } }$ would be the area covered by the plasma, ${ \text{d} \hat{ A }  }$ would be a normalized area differential, and ${ \hat{ n } }$ is the vector normal to the surface.  

### Induced EMF
Now we can calculate the induced EMF on the plasma loop due to this magnetic field flux. This is done by using Faraday's law of induction, which gives:

$$
\begin{align*}
    \varepsilon &=  - \dfrac{ d \Phi  }{ d t } \\
    &= - \left( \dfrac{ \mu_{ 0 } I_{ \text{max} } R_{ p } A_{ cs } }{ 4 \pi T } \right) \dfrac{ d I }{ d t } \int \vec{ F } \cdot \hat{ n } \text{d}{ A }
\end{align*}
$$

Where ${ I }$ (the dimensionless CS current profile) is the only thing that changes with time. Replacing values in the SI, we would get an EMF in volts (V).  

### Plasma resistivity
With $\varepsilon$, we can find the current ${ I_{ cs }  }$ that is induced into the plasma, through Ohm's law. But first we can notice that $\varepsilon$ is by default negative. However, if we want to obtain a positive value for the plasma current, and make it increase, which is what happens when you induce a current, we have to ignore the sign of $\varepsilon$.  
Electric potential differences are by convention negative. When measuring the voltage around a certain element in a circuit, we refer to it as a "potential drop". This is the same thing convened by Ohm's law. V is the potential drop (negative) due to a current ${ I }$ passing through a resistance ${ R }$. Then, it will be safe to ignore the sign of $\varepsilon$.  
After this, we would also need the resistance of the plasma, and for that we would first need its resistivity. We can find the resistivity as the Spitzer resistivity, using the formula:

$$
\begin{align*}
    \eta &= \dfrac{ \sqrt{ 2 } q_{ e } ^{ 2 } m_{ e } ^{ 1/2 } \ln\left( \Lambda  \right)  }{ 12 \pi ^{ 3/2 } \varepsilon_{ 0 }^{ 2 }  } \dfrac{ 1 }{ \left( k_{ B } T_{ p }  \right) ^{ 3/2 }  } 
\end{align*}
$$

Where ${ q_{ e }  }$ is the magnitude charge of an electron, ${ m_{ e }  }$ is its mass, ${ T_{ p }  }$ is the temperature of the plasma, and ${ \ln\left( \Lambda  \right)  }$ is its Coulomb logarithm.  
With this, we can find the resistance of the plasma as:

$$
\begin{align*}
    \rho  &=  \eta \dfrac{ L_{ p }  }{ A } 
\end{align*}
$$

Where ${ L_{ p }  }$ and ${ A }$ are the plasma's length (along the main axis) and cross sectional area, respectively. These can be treated as a constants of the system, so there is no need to normalize them (neither $\rho$, $\eta $, ${ L_{ p }  }$ nor ${ A }$).  

### Induced current
And finally we would find the induced current in the plasma as:

$$
\begin{align*}
    I_{ cs } &= \dfrac{ \varepsilon  }{ \rho  } \\
    &=  \left( \dfrac{ \mu_{ 0 } I_{ \text{max} } R_{ p } A_{ cs } }{ 4 \pi T \rho } \right) \dfrac{ d I }{ d t } \int \vec{ F } \cdot \hat{ n } \text{d}{ A }
\end{align*}
$$

And the plasma current density as:

$$
\begin{align*}
    \vec{ J } &= \dfrac{ I_{ cs } }{ A } \hat{ l } _{ p } \\
\end{align*}
$$

Where ${ \hat{ l }_{ p }  }$ is the direction in which the current flows through the plasma (given by the sign of $\Phi$ and the right hand rule).  
We could have also found the current density otherwise, by using the electric field induced into the plasma, found like:

$$
\begin{align*}
    \varepsilon &= - \int_{ P }  \vec{ E } \cdot  \text{d} \vec{ l } \\
    \\
    \vec{ E } &=  \dfrac{ \varepsilon  }{ L_{ p }  } \hat{ l } _{ p } 
\end{align*}
$$

Where the negative sign can again be ignored for the same reason.  
With this, we can then find the current density through the relation ${ \vec{ E } = \eta \vec{ J }  }$, which would give:

$$
\begin{align*}
    \vec{ J } &= \dfrac{ \varepsilon  }{ \eta L_{ p }  } \hat{ l } _{ p }\\
    &= \left( \dfrac{ \mu_{ 0 } I_{ \text{max} } R_{ p } A_{ cs } }{ 4 \pi T \eta L_{ p }  } \right) \hat{ l } _{ p } \dfrac{ d I }{ d t } \int \vec{ F } \cdot \hat{ n } \text{d}{ A } \\
\end{align*}
$$

Which is the same we find through the other method.  

## Bootstrap current
Now we would be in a position to calculate the current density that arises due to the diamagnetic properties of the plasma, which we will take to be the same as the bootstrap current for the case of the poloidal magnetic field. This current density will be given as:

$$
\begin{align*}
    \vec{ J } _{ B } &= \dfrac{ \vec{ B }_{ p }  \times \vec{ \nabla } p }{ B_{ p } ^{ 2 }  } 
\end{align*}
$$

Where, again, ${ \vec{ B }_{ p } }$ refers to the poloidal magnetic field, created by the plasma current, and ${ \vec{ \nabla } p }$ is the pressure gradient in the plasma. This current is calculated at a point inside of the plasma.  

### Particle density and gradient
The first thing we should find is the pressure gradient. For this, we first define the particle density gradient ${ \vec{ \nabla } n }$. If we have a total particle density of ${ n }$ in the whole (three dimensional) plasma, we can set it to be equal to a value ${ n_{ 0 }  }$ (unknown for now) all through the main axis of the plasma (corresponding to the center of the cross section), and to 0 at the boundary. The resulting linear gradient would then be written like:

$$
\begin{align*}
    \vec{ \nabla } n &=  \dfrac{ \Delta n }{ \Delta r } \hat{ r } \\
    &= - \dfrac{ n_{ 0 }  }{ L } \hat{ r } \\
    &= - \dfrac{ n }{ R_{ p }  } \dfrac{ n_{ 0 }  }{ L } \hat{ r } 
\end{align*}
$$

Where ${ L }$ is the distance from the center of the cross section to the boundary, and ${ \hat{ r }  }$ is the vector pointing in that direction. ${ n_{ 0 }  }$ and ${ L }$ will be made dimensionless by giving them as a fraction of their characteristic quantities (${ n }$ and ${ R_{ p }  }$ respectively).  
Once with the particle density gradient, we can also find the corresponding particle density at a given point like:

$$
\begin{align*}
    n\left( x,y \right) &=  \nabla n \left( L - r \right) \\
    &= n \ n_{ 0 } \left( 1- \dfrac{ \sqrt{ x^{ 2 } + y^{ 2 }  }  }{ L }  \right) 
\end{align*}
$$

Giving ${ x }$ and ${ y }$ also as fractions of ${ R_{ p }  }$.  
And if we add the particle density at each point, the total should be equal to the total density ${ n }$. With this, we can then find the value of ${ n_{ 0 }  }$ as:

$$
\begin{align*}
    \int \ \text{d}n\left( x, y \right)  &=  n\\
    \\
    n_{ 0 } &=  \dfrac{ 1 }{ \sum \left( 1 - \frac{ \sqrt{ x^{ 2 } + y^{ 2 }  }  }{ L }  \right)  } 
\end{align*}
$$

Where the summation is over all the points inside of the plasma.  
With this, we can then relate to the plasma pressure through the relation ${ p = n k_{ B } T_{ p }  }$. If we take the temperature of the plasma to be constant in all the plasma, then the gradient of the pressure would be written like:

$$
\begin{align*}
    \vec{ \nabla } p &=  k_{ B } T_{ p }  \vec{ \nabla } n\\
    &= - \dfrac{ n k_{ B } T_{ p }  }{ R_{ p }  }  \dfrac{ n_{ 0 } }{ L } \hat{ r } 
\end{align*}
$$

### Poloidal magnetic field
The next thing we could find is the magnetic field ${ \vec{ B }_{ p } }$. For that we can use Ampère's law (without the need for Maxwell's correction, given that the electric field will be constant), which says:

$$
\begin{align*}
    \vec{ \nabla } \times \vec{ B }_{ p } &= \mu_{ 0 }\vec{ j } \\
    \oint\limits_{ S } \vec{ B }_{ p } \cdot \text{d}\vec{ l } &= \mu_{ 0 } \int \vec{ j } \cdot \text{d} \vec{ A }
\end{align*}
$$

Where ${ \vec{ j } }$ is the current density at a given point.  
If ${ B_{ p } }$ does not change along the path ${ \vec{ l } }$, then we can take it out of the integral. Then, we would get:

$$
\begin{align*}
    B_{ p }  \oint\limits_{ S } \text{d} l &= \mu_{ 0 } \int \vec{ j } \cdot  \text{d} \vec{ A } \\
    \\
    \vec{ B } &= \mu_{ 0 } R_{ p } \hat{ l } _{ B }  \dfrac{ A_{ p } \int \vec{ j } \cdot \text{d} \vec{ \hat{ A }  } }{ P } 
\end{align*}
$$

Where ${ P }$ is the perimeter or length of the path that was integrated, and ${A_{ p }}$ is the area covered by that same path.  

### Current density
To continue we need a vale of ${ \vec{ j } }$ for all the points inside of the plasma. Given that ${ \vec{ J } = nq \vec{ v } }$, we will find these values similarly to how we found the values of the particle density at each point. If at each point the plasma carries particles of the same charge ${ q }$ at the same velocity ${ \vec{ v } }$, then at each point we will have:

$$
\begin{align*}
    q \vec{ v } &=  \dfrac{ \vec{ J }  }{ n } 
\end{align*}
$$

Where ${ \vec{ J } }$ is the total current density we found, and ${ n }$ is the total particle density.  
And with this, at a given point we will be able to write:

$$
\begin{align*}
    \vec{ j } \left( x, y \right) &=  n\left( x, y \right) q \vec{ v } \\
    &= \vec{ J } n_{ 0 } \left( 1- \dfrac{ \sqrt{ x^{ 2 } + y^{ 2 }  }  }{ L }  \right) 
\end{align*}
$$

And the poloidal magnetic field would be found like:

$$
\begin{align*}
    \vec{ B }_{ p } &= \mu_{ 0 } R_{ p } J \hat{ l } _{ B } \dfrac{ n_{ 0 } A_{ p }  }{ P } \int \left( 1- \dfrac{ \sqrt{ x^{ 2 } + y^{ 2 }  }  }{ L }  \right)  \text{d} \hat{ A } 
\end{align*}
$$

### Total plasma current
Now that we have both the pressure gradient and the magnetic field, we can find the current density (at a point) that rises as bootstrap like:

$$
\begin{align*}
    \vec{ j } _{ B } &=  \dfrac{ n k_{ B } T_{ p } }{ \mu_{ 0 } R_{ p } ^{ 2 } J } \dfrac{ P }{ L } \dfrac{ 1 }{ \int \left( 1 - \frac{ \sqrt{ x^{ 2 } + y^{ 2 }  }  }{ L }  \right)  \ \text{d} A  } \hat{ l } _{ B } \times \left( - \hat{ r }  \right) 
\end{align*}
$$

This bootstrap current density would be added to the overall current density at that same point, so in the end we would have a total current density for the plasma, that mixes the CS induced current as well as the bootstrap current.  
If we want to be able to analyze the effect of the bootstrap current individually, we can first find the total plasma current ${ I_{ p }  }$ like:

$$
\begin{align*}
    I_{ p } &= \int \vec{ j } \cdot  \text{d} \vec{ A } \\
    &= A \int j \text{d} \hat{ A } 
\end{align*}
$$

Where ${ A }$ is the cross sectional area of the plasma, and it points in the same direction as ${ \vec{ j } }$.  
Then, the current due to the bootstrap effect would be the difference between this total current, and the current that was induced by the central solenoid:

$$
\begin{align*}
    I_{ B } &= I_{ p } - I_{ cs } 
\end{align*}
$$
